# 🛰️ PRISM-RR Conecta: Laboratório de Disseminação Tecnológica

Este repositório centraliza os materiais didáticos, scripts, templates e códigos-fonte utilizados no eixo de **Formação e Nivelamento Técnico** do projeto de extensão **PRISM-RR Conecta: Rede de Disseminação Tecnológica**.

O objetivo deste laboratório é fornecer suporte prático aos minicursos e oficinas, promovendo o nivelamento de integrantes do grupo de pesquisa e da comunidade externa em tecnologias essenciais para PD&I.

## 📂 Estrutura do Repositório

O conteúdo está organizado por módulos temáticos, acompanhando o cronograma do ciclo de encontros:

* **/01-git-github**: Materiais sobre controle de versão, fluxos de trabalho colaborativos e boas práticas de desenvolvimento.
* **/02-escrita-latex**: Templates e guias para redação de artigos científicos e relatórios técnicos utilizando LaTeX.
* **/03-sistemas-embarcados**: Códigos de exemplo e fundamentos para o desenvolvimento de sistemas inteligentes e de baixo consumo.
* **/04-verificacao-testes**: Laboratórios focados em análise estática, verificação formal e testes automatizados em C, utilizando ferramentas como o **Map2Check**.
* **/05-decisao-engenharia**: Exemplos práticos de modelagem matemática e sistemas de decisão aplicados.

## 🛠️ Stack Tecnológica

As atividades práticas deste repositório envolvem o uso das seguintes tecnologias e ferramentas:

* **Linguagens:** C, LaTeX.
* **Controle de Versão:** Git e GitHub.
* **Verificação Formal:** Map2Check e analisadores automáticos.
* **Ambiente:** GCC, Makefiles e containers para padronização de build.

## 🚀 Como utilizar

1.  **Clone o repositório:**
    `git clone https://github.com/prismrr/prism-conecta-lab.git`
2.  **Acesse o módulo desejado:** Navegue até a pasta da oficina específica para encontrar as instruções e exercícios.
3.  **Ambiente Virtual:** Recomendamos o uso de ambientes configurados (via Docker ou Codespaces) para evitar conflitos de bibliotecas nos módulos de verificação formal.
